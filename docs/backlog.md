# Backlog — очередь задач

> Отсюда оркестратор берёт следующую задачу (сверху вниз по приоритету). Взятая помечается `[в работе]`; принятая — переносится строкой в `progress.md` («Сделано») и вычёркивается отсюда. Новые задачи от пользователя дописываются в конец соответствующего приоритета.

Засеяно роадмапом из анализа покрытия 2026-11-14 (~30 тестов) — правьте свободно.

## Формат задачи

- **Имя** — короткое, английское.
- **Цель (измеримая)** — какой результат считаем успехом; без «сделать лучше».
- **Done when** — точная команда проверки.
- **Срок** — дата или веха; необязательно, но полезно.
- **Заметки** — контекст для оркестратора (builder'у идёт только бриф).
