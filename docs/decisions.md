- 2026-11-24: перед параллельной волной UI оркестратор САМ регистрирует плановые `check*`-имена в eslint (главный конфликт-файл снят с builder'ов); неиспользованные имена вычищаются на приёмке. Итог: 5 параллельных builder'ов без единого конфликта.
